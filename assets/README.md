# Assets Folder

Lege deine Bilder und Logos hier ab:

## Logos (`/logos/`)
Dateinamen die die Website erwartet:

| Datei                     | Verwendung             |
|--------------------------|------------------------|
| `logos/orbitcheats.png`  | OrbitCheats Logo       |
| `logos/stormai.png`      | Storm AI Logo          |
| `logos/modsync.png`      | ModSync Logo           |
| `logos/nextpay.png`      | NextPay Logo           |
| `logos/devion.png`       | Devion Logo            |

## Empfehlungen
- **Format:** PNG oder SVG (transparent bevorzugt)
- **Größe:** ca. 200×200px für Logos (werden automatisch skaliert)
- **Avatar:** Optional — wird automatisch von Discord geladen

Sobald du die Dateien hier ablegst, erscheinen sie automatisch auf der Website.
